## 配音说明

- 语速按每秒 4–4.5 字估算；旁白列即逐字稿；
- 若不配音，烧录字幕已覆盖全部信息，静音成片可直接使用；
- 录屏替换方案：任何一段都可以换成实时操作画面——离线面板断网可录（分镜 3/4/8/9），在线 trace 需本地 llama.cpp + CPA。

## 复现

```bash
python -m demo.server                # 离线模式（默认）
python demo/make_video.py            # 重新生成本视频（需 ffmpeg 与 Edge）
```
